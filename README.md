# Student QR Attendance System

A Python-based Student QR Attendance System using SQLite.

## Features

- Student registration
- Student login
- Personal QR code
- QR code scanning using cellphone camera
- Automatic attendance recording
- Date and time recording
- Subject and schedule management
- Admin attendance monitoring
- Forgot password using Student ID

## Technologies

- Python
- Tkinter
- SQLite
- Flask
- QR Code
- HTML/JavaScript for phone camera scanning

## Project Files

- `main.py` - Main application
- `login.py` - Student login and QR display
- `register.py` - Student registration
- `database.py` - SQLite database
- `scanner_server.py` - Phone QR scanner server
- `qr_scanner.py` - QR attendance processing
- `admin.py` - Admin functions
- `dashboard.py` - Dashboard
